# 성호 ♥ 유민 결혼식 · 아율이 돌잔치 사회 대본 (보기용 페이지)

- 페이지: https://redstar1492-design.github.io/sungho-yumin-mc/
- 원본: 구글 문서 (사회자·신랑신부가 여기서 고칩니다). 페이지를 열면 구글 문서의 최신 내용을 바로 가져오고, 열어 둔 동안 1분마다 다시 확인합니다. 문서를 고친 뒤 페이지를 새로고침하면 바로 보입니다.
- 대비용 저장본: GitHub가 10분마다(늦어질 수 있음) 문서를 읽어 저장본을 갱신합니다. 페이지가 문서를 못 읽을 때 저장본을 보여 줍니다.
- 서식 규칙: 회색 기울임 = 진행 안내(읽지 않음), 빨간 굵은 글씨 = 구령. 문서에서 이 두 색을 그대로 쓰면 페이지에도 같은 모양으로 나옵니다.
- 바로 반영하려면: 저장소 Actions › '구글 문서 → 페이지 반영' › Run workflow.
- 변환: `tools/convert.js`(페이지와 빌드가 같이 씀), `tools/build.cjs`. 외부 패키지 없음.
