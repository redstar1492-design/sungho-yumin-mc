# 성호 ♥ 유민 결혼식 · 아율이 돌잔치 사회 대본 (보기용 페이지)

- 페이지: https://redstar1492-design.github.io/sungho-yumin-mc/
- 원본: 구글 문서 (사회자·신랑신부가 여기서 고칩니다). 페이지는 이 문서를 10분마다 읽어 내용이 바뀌었을 때만 다시 올립니다.
- 서식 규칙: 회색 기울임 = 진행 안내(읽지 않음), 빨간 굵은 글씨 = 구령. 문서에서 이 두 색을 그대로 쓰면 페이지에도 같은 모양으로 나옵니다.
- 바로 반영하려면: 저장소 Actions › '구글 문서 → 페이지 반영' › Run workflow.
- 변환: `tools/build.cjs` (외부 패키지 없음).
